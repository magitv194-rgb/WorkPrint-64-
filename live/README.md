# WorkPrint 64 Linux image

This directory contains the first reproducible live-build configuration for WorkPrint 64.

## Base

- Debian 13 (Trixie), amd64.
- XFCE desktop and LightDM.
- Firefox ESR.
- CUPS, system-config-printer, IPP-USB and selected open printer drivers.
- Spanish (Argentina) locale and Latin American keyboard layout.

Debian 13 Trixie is the current stable release as of November 2026. See the official [Debian releases](https://www.debian.org/releases/) page.

## Build on a Debian 13 amd64 host

Install build dependencies:

```sh
sudo apt update
sudo apt install live-build debootstrap xorriso squashfs-tools
```

From the repository root:

```sh
cd live
make check
sudo make config
sudo make build
```

The resulting image is generated by live-build in this directory. Exact output filenames depend on the live-build version.

## Validation status

The Debian 13 Trixie amd64 hybrid ISO has passed the automated build, package/configuration checks, El Torito boot-catalog inspection and artifact upload. A subsequent QEMU smoke test with 3072 MB RAM reached the XFCE live desktop; the captured guest screenshot was inspected manually.

See the [QEMU test evidence](https://github.com/magitv194-rgb/WorkPrint-64-/actions/runs/44806112856) and the [validation plan](../docs/TEST_PLAN.md).

This is still a development image. The QEMU result does not prove compatibility with the Lenovo, network or audio operation, browser performance, or physical printer support.

The Lenovo's CPU must support x86_64 for this amd64 image. Do not install to its internal disk. Write the ISO to a USB drive only after verifying the downloaded artifact and selecting the correct removable device.

3 GB RAM is a constrained target for a modern browser. Firefox ESR is included as a starting point; memory use and WhatsApp Web compatibility must be tested. Printer support depends on the exact printer model, firmware and available driver. USB detection alone does not guarantee printing.
